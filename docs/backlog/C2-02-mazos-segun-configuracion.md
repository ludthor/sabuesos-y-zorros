# C2-02 · Mazos según la configuración

Como organizador, quiero indicar cuántos zorros y sabuesos juegan para que los mazos se ajusten solos.

## Criterios de aceptación

- Dado un solo zorro, entonces se retiran Hermandad y Olfato aguzado.
- Dado un solo sabueso, entonces se retiran Jauría feroz y Silencio nocturno.
- Dado modo ensayo, entonces las cartas marcadas E se quedan en el mazo.

## Notas

- Comprobar el resultado contra la tabla «Mazos según la configuración» del §7.

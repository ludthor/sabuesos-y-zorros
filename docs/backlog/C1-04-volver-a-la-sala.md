# C1-04 · Volver a la sala

Como jugador, quiero que mi dispositivo vuelva a la sala con mi bando si se bloquea o se recarga la página para no interrumpir la partida.

## Criterios de aceptación

- Dado un móvil que se bloquea dos minutos, cuando se desbloquea, entonces muestra el estado actual sin volver a introducir el código.
- Dado una recarga de la página, entonces el dispositivo conserva su bando.

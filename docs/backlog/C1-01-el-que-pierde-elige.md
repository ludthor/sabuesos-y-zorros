# C1-01 · El que pierde elige territorio

Como bando que acaba de perder un territorio, quiero elegir el siguiente para recuperar iniciativa.

## Criterios de aceptación

- Dado que un territorio se resuelve, entonces el dispositivo del bando perdedor muestra los territorios pendientes para elegir.
- Dado que el otro bando intenta elegir, entonces la app no se lo permite.
